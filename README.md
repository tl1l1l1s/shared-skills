# skills

Claude Code 스킬과 프레임워크를 모아 공유하는 레포.

## 목록

### [log](log/) — 개발 성장 기록 프레임워크

매일 흩어지는 개발 기록(inbox 메모, Claude Code 세션, GitHub 활동)과 할 일을 로컬 파일에 정리하고, 남길 경험만 골라 Portfolio Seed로 뽑는다.

- 커맨드: `/plan-daily`(아침 standup), `/log`(하루 중 기록), `/close-daily`(상세 마감), `/review-weekly`(주간 검토와 Portfolio Seed 추출)
- 로컬 파일이 원본이고 Notion은 선택이다. 설치·세팅은 [log/README.md](log/README.md) 참고.

### [cover-letter](cover-letter/) — 자소서 작성 스킬

회사 자기소개서를 함께 쓴다. 회사 조사부터 소재 후보, 구조 설계, 초안, 다듬기까지. 본인 목소리와 검증된 프롬프트로.

- `log`와 독립이라 이 스킬만 써도 된다. 소재는 Notion 페이지나 로컬 파일 중 택.
- 자세한 건 [cover-letter/README.md](cover-letter/README.md) 참고.
