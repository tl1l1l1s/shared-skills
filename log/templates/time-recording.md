# 시간 기록과 참고값

원본은 `workspace/estimates.md`다. standup과 `/log`의 가벼운 정리 또는 `/close-daily`에서 `날짜 | 항목 | 예상 | 실제 | 편차 | 비고` 형식으로 기록한다. 과거 행을 삭제·수정하거나 뒤늦게 실측값처럼 보정하지 않는다. 정정이 필요하면 원본 행을 가리키는 정정 행을 남긴다.

## 저장

- 할 일 칸이나 자유 메모에서 예상이나 실제 소요가 하나라도 명시된 작업을 기록한다. 예상 없이 “약 40분 걸림”만 있어도 예상 `-`, 실제 `약 40m`, 편차 `-`로 저장한다. 시간 언급 없는 완료는 Daily Log에 남기며 시간 행을 억지로 만들지 않는다.
- 예상은 사용자 값과 AI 제안을 구분한다. 할 일 칸의 `예상 30m`은 사용자 값, `참고 60m`은 estimates의 과거 실제 중간값으로 만든 AI 제안이다. 그 줄의 실제가 기록되면 예상 칸에 숫자를 쓰고 비고에 `사용자 예상` 또는 `참고 예상`을 적어 편차를 계산한다. 실제는 사용자 명시/직접 작업 구간/경과 시간/세션 시간/병렬 배분 불명/기록 없음으로 비고에 구분하고 원본 일지·작업 ID를 연결한다. 선택한 동일 범위의 작업만 비교한다.
- inbox 할 일 칸 하위 줄의 시간은 사용자가 명시한 직접 작업 구간이다. 여러 구간은 합해 실제로 쓰고 비고에 구간 원문을 남긴다. 다른 줄의 구간과 겹치면 겹친 부분은 아래 병렬 규칙을 따른다. AI가 결과를 내기까지 걸린 시간은 묻거나 기록하지 않는다.
- `미진행`, `미착수`, `기록 없음`은 숫자 0으로 바꾸지 않는다. 날짜·구간·작업 연결이 불명확하면 추정하지 않는다. 자정을 넘긴 구간은 날짜 근거가 있을 때만 계산한다.
- 병렬 구간은 각 작업에 전체 시간을 중복 배분하지 않는다. 분리 근거가 없으면 실제 `배분 미상`, 비고에 원래 경과 시간과 병렬 작업을 남긴다. AI 실행·대기와 대화 세션 길이를 사용자의 직접 투입 시간으로 간주하지 않는다.
- 편차는 같은 범위·시간 성격의 예상과 실제가 모두 수치로 확인될 때만 계산한다. 범위 추정·병렬 배분 불명·일부만 완료된 작업은 `-`다. 메모 ID가 있으면 비고에 보존하며 같은 ID를 가벼운 정리와 상세 마감에서 공유한다. 재실행 시 같은 메모·시간 항목을 중복 추가하지 않는다. ID 없는 과거 행은 날짜·항목·원본 근거로 대조한다.
