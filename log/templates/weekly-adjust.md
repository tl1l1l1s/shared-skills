# 짧은 주간 조정

기본 standup의 그 주 첫 실행에서만 필요한 절차다. 긴 회고·기록 마감·Notion 게시를 실행하지 않는다. Notion은 조회하지 않는다.

## 대상 주와 중복 방지

- 사용자 현지 날짜(기본 Asia/Seoul)의 ISO 주년·주차 `YYYY-Www`를 사용한다. 달력 연도와 ISO 주년을 혼동하지 않는다. standup의 조정은 현재 주, 명시적인 다음 주 요청은 다음 주 월요일이 속한 주를 대상으로 한다. 월요일에 실행하지 않았어도 그 주 첫 실행에서 진행한다.
- `workspace/tasks.md`의 `주간 조정 상태`에서 대상 주를 찾는다. 없으면 기존 `확정 주`와 해당 주 확정 약속도 확인한다. 일요일 `/review-weekly`로 다음 주를 이미 확정했다면 월요일에 재생성하지 않는다. 다음 주 상태를 기록할 때 현재 주 상태도 보존한다.
- `확정`: 기존 주간 계획으로 오늘 계획을 만든다. 새 마감·막힘은 오늘 브리핑에 반영하며 주간 조정 전체를 자동 재실행하지 않는다.
- `제안`: 저장된 제안을 재사용한다. 다음 실행에서 답을 재촉하거나 질문을 반복하지 않고 미확정이라는 사실만 표시한다. 새 사실이 생기면 영향받는 항목만 수정하며 승인 없이는 확정하지 않는다.
- `보류`: 사용자가 해당 주 조정을 건너뛰겠다고 한 상태다. 그 주에는 자동으로 다시 묻지 않는다. 명시적 조정 요청은 어느 상태에서도 가능하다.
- 대상 주 상태가 없을 때만 아래 제안을 만든다. 처음 사용하는 경우에도 지난 주들을 소급 회고하지 않는다.

## 한 번의 짧은 제안

standup에서 이미 읽은 자료를 재사용한다. 현재 미완료 작업·월간 결과와 연결된 약속·이번 주 일정·이번 주 및 다음 주 마감만 사용한다. 전체 작업 목록을 출력하지 않고 결과 1~3개와 미룰 일을 제안한다. 마감이 지났다고 완료·취소로 처리하지 않는다. 완료 여부가 불명확하면 그 사실을 표시한다.

몇 주째 남아 있는 작업도 현재 tasks.md에 실제 진전일이나 반복 이월 근거가 있을 때만 확인한다. 2주 이상 진전이 없다고 확인되는 작업 중 최대 1개에 대해 다음 행동을 더 작게 나누거나 보류하는 안을 함께 제안한다. 근거 날짜가 없으면 오래 방치했다고 단정하거나 과거 일지를 전수 탐색하지 않는다. 사용자가 정한 재검토일 전에는 다시 묻지 않고, 같은 주에 같은 제안을 반복하지 않는다. 이 질문은 주간 확인 질문 하나에 포함한다.

각 결과는 작업 이름, 완료 기준, 연결된 월간 결과(있을 때)를 붙인다. 미룰 일은 유지/축소/보류/취소의 제안과 이유만 보여준다. 기존 마감은 임의 변경하지 않는다. 가용 시간을 모르면 완료 가능성을 보장하지 않고 잠정 분량으로 둔다. 목표나 일을 만들 근거가 없으면 지어내지 말고 이번 주 우선할 일을 질문한다.

주간 제안은 5줄 안팎으로, 오늘 브리핑과 합쳐 보통 10줄 이내로 제시한다. “이번 주는 이렇게 잡을까요?” 한 번만 묻는다. 오늘 우선순위에 꼭 필요한 확인이 있다면 같은 질문에 합치고 질문을 연달아 추가하지 않는다. 사용자가 이미 구체적으로 지시한 내용은 다시 승인받지 않는다.

## 규칙 수정안

`workspace/standup-review.md`에 처리 칸이 빈 행이 있으면 모두 읽고 주간 제안 끝에 `.claude/commands/plan-daily.md`나 `templates/quick-record.md`에 넣거나 바꿀 문장 한 줄을 붙인다. 줄 끝에 근거가 된 행의 날짜와 종류를 괄호로 적는다. 근거 행이 없으면 붙이지 않고 질문도 늘리지 않는다. 사용자가 반영하라고 할 때만 해당 문서를 고친다. 읽은 행의 처리 칸에는 대상 주(`2025-W11`)를, 반영한 행에는 `2025-W11 반영`을 적는다.

## 저장과 오늘 계획 연결

제안 시 `tasks.md`의 `재계획 제안`에 대상 주와 내용을 저장하고 이전 주 제안은 지우며 아래 상태 행을 추가·갱신한다. 기존 파일에 이 섹션이 없으면 추가한다. 제안이 보존되지 않았으면 상태만 저장하지 않는다.

```md
## 주간 조정 상태
| ISO 주 | 상태 | 갱신일 |
|---|---|---|
```

답이 없으면 `제안`으로 남기고 기존 약속·확정 주는 유지한다. 오늘 할 일 칸은 제안과 확정 사실을 구분해 쓴 뒤 종료한다. 승인하면 해당 주 약속과 관련 작업 연결을 갱신하고 `확정`으로 바꾸며 `확정 주`도 갱신한다. 해당 주를 명시적으로 건너뛰겠다고 하면 `보류`로 둔다. 일부만 승인하면 승인된 항목만 반영하고 남은 제안은 미확정으로 유지한다. 해당 주의 변경안 처리가 끝났을 때만 주 전체를 `확정`으로 표시한다.

짧은 조정은 tasks.md만 갱신하며 별도 주간 요약 문서나 외부 게시를 만들지 않는다. 상세 `/review-weekly`도 같은 주차별 상태를 사용한다. 일요일 밤에 다음 주를 미리 정하려면 사용자가 그때 `/review-weekly`를 실행한다.
